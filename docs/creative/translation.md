# 嵌字翻译

本文仅在制作或修正多语言成品时读取。工具操作见[集成说明](../agent/README.md)，数据格式见[项目事实](../reference/project-files.md)中的 Schema 入口。

- 中文为原文，在其基础上增加英文、日文译文；只翻译成品嵌字和文字页的显示标题、正文，保留中文和底图。译文可由人手写或由 Agent 写入，不要求逐条人工校对。
- 以读懂剧情为目标，保留原意与人物语气，允许简洁意译。日文横排；嵌字大小尽量接近中文，篇幅过长时优先缩短表达，输出前检查溢出。
- 翻译前查阅项目中的翻译参考资料；没有专门说明时，读取与本次专名相关的角色、世界观资料。已有资料已读且未变化时复用，不重复通读。
- 角色名、地名、机构名和作品术语，优先采用用户明确指定的项目译法；其余按项目参考资料指向的原作目标语言文本核对。优先使用名称字段，必要时核对上下文，避免混用同名对象或不同场景的译文；不能仅凭中文音译猜名字。
- 同批次复用已核对的对照；控制长度时保留正确专名，优先缩短周围表达。原创词或来源缺失时保持译法一致，并在交付中说明未核实项。项目参考资料维护来源、查询入口及必要的项目专用约定，通用原则只维护在本文。
- 译文记录对应中文原文的指纹；原文变化后复查失效条目，修正专名时只改受影响译文，再制作对应语言成品。不得仅刷新指纹来消除失效状态。
