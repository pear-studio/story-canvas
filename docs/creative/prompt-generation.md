# Prompt 与生成协作

本文维护模型无关的编写和交付规则；操作契约查 `story_canvas` help。日常插画使用 Anima，动态页使用 H3；备用 Qwen 按需读[专用文档](../reference/qwen.md)。

## 表达与修正

- Prompt 优化保持已确认画面不变，只改善模型对同一目标的表达。画面方案调整遵循[创作确认](guide.md#确认边界)。
- 优先复用上游稳定表达，本页只补当前需要。修正先删除重复、矛盾、无关词，重新组织整页，不逐轮叠加补丁。
- 模型注意力有限，检查整页描述总量，只在少数关键结构或关系使用具体限制；不逐部位、逐步骤指导动作。
- 动作／关系描述尽量单条不超过 20 个英文单词；必要说明可稍长，不拆条绕过。它是辅助规范，不是保存或生成门槛。
- Anima 词条权重优先选网页预设，不自主细分；已有值不自动取整，用户明确指定优先。此偏好不用于 LoRA 权重，预设数值查工具字段帮助。
- 任何 LoRA 新增、删除、替换都须用户明确同意。自动纠错不改变画面、参考图、LoRA 或生成参数。

## 生成与交付

- 数量沿用工具的图片／视频默认值；用户明确的数量、范围和预算优先。只委托文本时不自动出图。
- 插画至少两张有明显结构错误或偏离核心人物、动作、关系目标时，可自动修正 Prompt 后再生成，首轮后最多三轮。轻微瑕疵和审美差异不触发；服务失败先处理环境，不无限重提。
- 视频耗时较长，不自动修正或重试，根据用户反馈调整；连续播放验收，抽帧不能证明全程或循环接缝正确。
- 不推荐、排名或替用户选图，不解释各批次。新候选成功并匹配当前输入后清理旧 Prompt 对应候选，保留成品仍引用的候选；安全顺序查 `candidate.cleanup.preview` help。
- 交付最新结果入口和仍存在的主要问题，用户自行微调、重生成和选图。

按需比较模型或参数时使用 `comparison` 工具；同种子不保证构图一致，多因素同时变化只代表组合差异，少量结果不能证明稳定性。
