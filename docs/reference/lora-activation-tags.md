# LoRA 激活标签

激活标签／触发词是调用训练概念的文本，不是文件名、资源 ID 或随机种子；可为空。

## 选择

| 目标 | 建议 |
|---|---|
| 底模已认识的角色 | 核对规范角色及作品标签，仅隔离特定版本时再设别名 |
| 原创角色 | 简短、稳定、可读、低冲突的名字，不用宽泛类别词或 UUID |
| 服装、道具、场景 | 需要独立调用且数据有变化覆盖时才设标签 |
| 画风、整体质感 | 通常由加载权重生效；需独立控制时再设标签 |
| 多个概念 | 每个标签对应可独立调用的概念，只写实际出现的标签 |

质量词、动作词和推荐 Prompt 不属于激活标签。始终共现的概念不会因取了两个名字就解耦。

## 与 Caption 的关系

- 先决定身份由哪个词承担，再检查固定外观是否重复绑定；不机械追加到全部图片。
- 固定特征由身份词承载时可减少重复；需要显式控制的外观按实际目标保留。
- 触发词不能无损重命名，新旧词共同训练不保证新词独立替代旧词。
- 比较调用方式保留无 LoRA 条件，区分底模词响应和训练收益。
- `activation_terms` 随 run 冻结，正式登记依据快照，不依据后来改过的当前设置。
- 声明词未出现于任何启用 Caption 时预检提示；不设词本身不是错误。

模型当前能力、Caption 确认与流程见[LoRA 训练](lora-training.md)。工作台直接读取本文件展示，保留独立入口。
