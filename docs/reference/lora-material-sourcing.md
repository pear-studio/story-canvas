# 素材来源参考

操作流程由 `lora-material-sourcing` 技能维护；本文只存来源辨认与原图获取要点。筛选后的导入见[LoRA 训练](lora-training.md)。

## 原图与身份

- 作者页、官方页优先；Wiki、图站标签和搜索摘要只作回溯线索，不证明身份或造型。
- 关联作者、作品页、原图地址和文件名；转载、视频封面如实标明，不称作者原图。
- 缩略图、差分、重采样和转载按独立画面信息去重，不按文件数累积。
- 明确禁止 AI 使用的作品不加入训练候选；未见限制不等于授权，站点 AI 标记也不独立证明绘制方式。

## 获取入口

| 来源 | 线索与限制 |
|---|---|
| Pixiv | 作品页及多页信息提供原图线索；核对页数、限制，原图可能需正常浏览器来源头，不凭 ID 猜地址 |
| Zerochan 等图站 | 沿 source 回作者页，full 图仍属于转载来源 |
| Bilibili | 区分动态原图、图文、封面、游戏截图与社区 3D；封面可能裁过画幅 |
| 官方资源 | 查看公告链接的完整媒体包或共享目录，避免只取得预览或重复立绘 |

响应字段和访问条件以实际页面为准，失效入口不保留为可用保证。

## 视频与访问限制

- 403、空列表或失效页面区分“无法访问”和“没有素材”；少量验证后换公开来源，不反复请求失败入口。
- 测试版、爆料和未发布造型标明不确定性，回溯源视频。
- 按姿态、镜头及可见细节选帧，不按固定间隔凑数量；画幅分辨率不代表人物清楚。
- 签名、UI 或文字不自动淘汰；保留原图，裁剪会损伤关键部位时说明限制。
- 保留内容必须实际解码、查看、去重；其他 Agent 的采集也纳入同一次复核。
