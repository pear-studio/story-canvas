# 视觉页面参考

创作节奏、职责、用户确认和停止条件统一见[创作指南](../creative/guide.md)。本页说明页面操作、候选与嵌字；具体数据结构以[项目文件](project-files.md)为准。

## 页面与准备

所有视觉页由 pages/index.json、content 与 Prompt 组成。剧情、角色和场景仅归属位置不同，均可引用多个角色子设定和一个场景子设定。新建验证页默认填入所属设定，后续允许移除或替换；移动归属不改引用。画外对白不会自动把说话人加入生成角色。字段与命令见[直接操作入口](agent-interfaces.md)。

单元分页草案包含基本画面、基础文案分配和简短机位建议，用户确认后再执行。基础文案原样落实，文案优化另行处理。画面内容简短白描，20 字为创作规范，不是生成门槛。

新增角色子设定先经用户同意，再单独生成验证图，用户验收后才能用于页面。验证页只补展示所需的人数、姿态和机位，不重复完整角色描述。已验收且未变的配置复用。

准备 Prompt 时核对当前确认稿、实际角色配置及有效生成配置。机位优先用 camera:prompt 生成带参数标记的片段，再通过 read/save 保存；详见[机位控制](prompt.md#机位控制)。

## 编译预览与生成

Agent 日常操作需要工作台在线。修改前 read，保存后阅读 audit，再预览最终输入：

```powershell
npm --prefix <仓库根绝对路径>/app run visual:produce -- preview page <project-id> <page-id>
npm --prefix <仓库根绝对路径>/app run visual:produce -- render page <project-id> <page-id> --count 3 --wait
```

preview 返回最终正负向、来源、审计与配置诊断。当前 inspection.prompt.signature 与候选 result.json 的 prompt_signature 相同，说明候选对应当前编译输入。渲染从提交时的最新稳定事实冻结，不携带项目 revision，不接受临时 Prompt 覆盖。固定种子 --seed 仅用于受控对照。

render 默认排队后返回；需要等待结果时加 --wait。任务返回完整 task_directory 与 candidate_paths，直接按路径查看，不拼文件名。当前范围内已准备好的独立页面可并发提交，依赖当前结果的改法不得预排；切换方案前确认旧任务已冻结。

## 默认检查与一次修正

每页默认生成三张，逐张检查严重问题，全部保留给用户，不筛选或自动删除。额外人物、主体错误、严重肢体错位等属于严重问题；一般构图偏好、审美差异和轻微瑕疵不触发自动重试。

三张中至少两张严重出错，可在当前事实范围内修正一次 Prompt，再生成三张。第二批仍有问题就说明后交付，不继续补样，也不为凑可用图降低目标。不要删除失败批次来隐藏问题。用户明确的数量、范围和专项试验预算优先。

若问题需要改故事或方向，先提出具体影响交用户讨论；若只是普通首轮不够精致，交用户调整。不得自动升级为视觉探索、受控实验或范围外重生成。交付不经过多层内容就绪审批，也不代表最终验收。

## 候选管理能力

用户在浏览器查看候选并完成后续选择。普通原型保留全部候选；用户明确要求清理时，才使用现有删除入口，活动任务和成品引用保护由服务端处理：

```powershell
npm --prefix <仓库根绝对路径>/app run visual:produce -- candidate delete <project-id> <page-id> <absolute-candidate-path>
```

切换候选只是预览，不改写角色、narrative 或 Prompt；保存并输出成品另有制作记录。用户可在浏览器编辑 Prompt 并明确保存，文字样式由用户控制。

## 文字页

文字页（narrative 带 `page_kind: "text"`）不生成候选图，用于标题、转场和说明。导航树情节单元右键「新建文字页」创建，类型创建后不可转换。

- `title` 只用于目录名称；`display_title` 是独立显示标题，缺省或留空时不显示、不占位；`body` 正文也可留空，两者支持换行。
- 标题和正文分别设置字号（12–192，以 1024 宽逻辑画布计）及左／中／右对齐，字体沿用项目设置；新页默认字号为 62／28。
- 整组位置为上三分之一、居中或下三分之一，表示整组文字的中心高度；切换位置不改变字号与对齐。长文靠近边缘时向内收，保留上下 8% 留白；超出可用空间时提示，并阻止截断输出。
- 黑底浅色字、固定宽度和间距，不提供自由拖动。预览与成品共用排版组件，设置通过页面「保存」持久化。

文字页直接「输出成品」，尺寸为当前渲染 recipe 的候选尺寸两倍，与其他页一起进入成品列表和 ZIP 导出。

## 嵌字与收尾

所有图片页的对白、心理活动、旁白和爱心文案保存在 content；新增文案由服务端生成 ID。对白布局独立保存，
不复制文案。排版默认叠加到当前候选预览上，可直接拖动，文案与布局通过页面顶部的「保存」一起保存，角色显示颜色由用户控制。当前工作台提供嵌字预览，
在候选预览下点击「保存并输出成品」可对选定候选做 2 倍超分并生成嵌字版和无字版；导航树「成品」提供查看、替换、系列图片 ZIP 导出和 1024px 轻量预览 HTML 导出；系列导出仅遍历剧情目录，验证图支持单页输出。制作记录进入项目 Git，不备份底图，不自动提交。详见 [成品输出](../dev/finished-pages.md)。

旁白是特殊格式文案：每页至多一条、100 字以内，在嵌字页签顶部的专属文本框编辑，不占「文案类型」选项；
画面上的位置完全自动——渲染为通栏渐隐字幕条，可按页选择底部或顶部（默认底部），浅色文字带阴影，沿用项目统一字体字号，不可拖动、不可选中，
也不保存逐页布局。清空文本框即删除该页旁白。

文案类型可选择「爱心」：横排志莽行、统一粉色白边，自动生成有效字数＋1～2 个装饰爱心，
标点与拖音符号不计数。新增文案即可在「嵌字」预览并选中该条，通过右下角手柄调整独立字号（默认 48）、上方圆形手柄调整排布方向，
或点击骰子图标重新排列，最后点击页面顶部「保存」。拖动爱心选框角标会同步缩放文字、装饰、白边和间距；
增加文字只延长组合，不自动缩小。普通文字仍通过框宽／列高控制换行，不提供独立缩放和旋转。
方向手柄只改变各字和爱心中心的排布方向，字形与爱心始终正立。爱心的「重置」恢复默认位置、字号、方向和种子，
「重置所有布局」对全部文案恢复默认；普通文字仅恢复位置。切换候选或重新打开页面不会重新抽样。

每轮结束说明当前范围、实际改动、结果入口和主要问题；不自动继续下一阶段。
生成图片成为后续必需参考时，先提升到项目 `materials/` 再持久使用。
