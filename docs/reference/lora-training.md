# LoRA 训练知识

工作台支持 Anima、Qwen-Image-2.1 和 MOSS 新训练，共用素材管理和运行流程。MOSS 默认使用 SFT BF16 训练；具体底座身份和配方以 `library/lora-training/` 为准。Anima 与 MOSS 暂不提供精确续训，Qwen 保留冻结状态续训。配方是迭代起点，不是质量保证。

流程由 `lora-training` 技能维护；数据、确认、预检和运行操作查工具 help。环境见[搭建](setup.md)及[Qwen](qwen.md#训练环境)，存储见[项目事实](project-files.md)。

## 数据与 Caption 判断

- 一个训练项目共用素材筛选、分组、裁剪和图像处理；打标集独立于模型，可被多个模型配置引用。每个模型一套当前配置，同方向调参更新当前设置，各 run 保存冻结输入，不为每轮复制项目或素材。
- 用户筛选后的目录是导入依据，不补回已删图片。裁剪保留身份与造型，不为统一画幅切掉关键部位，不机械增加近重复裁片；抠图按需。
- 准备图像的质量评分用于处理选择，不代表细节保真或训练效果。图片稳定后再判断 Caption。
- Caption 可用标签或自然语言，不自动改格式或增删触发词；只描述真实可见信息。检查身份是否重复绑定，服装、动作、镜头和背景是否随图变化。
- 所选打标集的最终 Caption 是训练文本，自动基础 Prompt 和 raw tags 是复核起点；runner 不改写、打乱或追加触发词。自然语言由 Agent 写入，网页提供查看、修改和确认，不主动调用视觉模型打标。激活词判断只维护在[激活标签](lora-activation-tags.md)，工具读取同一文件。
- Caption 操作明确指定打标集，训练操作明确指定模型。图片变化使该图各套打标确认失效；修改某套文本只影响本集。复制打标集不复制确认与审计，新图在各集保持未打标。
- 素材确认与图片审计是两件事：确认绑定当前图片和 Caption，审计记录实际看过的图片，不能互相替代。具体哈希及失效条件查 `training.caption.*`、`training.audit.*` help。

## 训练与续训

- step、保存间隔和预算指 optimizer 更新；梯度累积增加处理张次，不再乘一次 repeats。Loss 和性能是诊断，不是质量评分。
- recipe 定义语义，运行设置定义预算；已引用配方不原地改语义，基线变化用新版本。
- Anima 使用 Base v1，只训练 DiT，不训练文本编码器或 LLM adapter；Alpha 随 Rank。默认不做 block swap，显存不足可先降低 micro batch、增加梯度累积以保持有效 batch；训练步数不固定绑定图片数量。
- Anima 停止在完整更新步后保存 LoRA 权重；不保存完整优化器恢复状态，强制终止仍可能丢失当前步。Qwen 保留完整状态续训。
- MOSS 使用独立训练环境和显式 SFT 权重映射；环境、模型身份或格式不符合时预检阻止运行，不回退 Base 或量化底座。
- 没有跨进程 GPU 调度器。训练前检查 ComfyUI 队列，空闲时释放驻留模型；训练中不另占同一 GPU 生成。
- run 按冻结 manifest 解释，后来改素材或参数不影响它。续训沿用冻结数据和参数；改变训练语义应从头训练。允许的预算调整和恢复点条件查 `training.run.resume`。
- 停止不等于得到任意当前步恢复点，强制中断可能回退；结构化状态是依据，重启不自动继续。

## 分析与登记

训练器没有内置预览，用现有 comparison 工具对比 checkpoint；少量样本不能证明稳定效果。用户选定结果并授权后按[资源规范](../../library/resources/README.md)登记，以对应 manifest 记录底座、用途、激活词、文件身份和训练来源，不从文件名猜测，不自动升为全局资源。
