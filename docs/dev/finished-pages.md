# 成品输出

当前实现面向剧情页。页面候选区的「保存并输出成品」先调用已有保存入口，再冻结指定候选、
文案与布局。导航树「成品」按当前章节和页面 index 展示，不维护另一份顺序。

## 文件与执行

- `finished/<page-id>.json` 是当前成品制作记录，进入项目 Git 与项目复制，参与事实 revision；
  记录候选 ID、源图 SHA、seed／实际执行 seed、最终 Prompt、模型／LoRA、采样参数、
  文案／布局／样式、超分模型和输出尺寸。契约见 `library/schemas/finished-page.schema.json`。
  文字页（`page_kind: "text"`）的记录不带候选与超分字段，只保存显示标题／正文／文字页排版、项目字体与画布；目录名称不进入画面快照，修改目录名称不会使成品过期。文字溢出时拒绝输出。
- `Outputs/finished/<page-id>/<output-id>/{clean,lettered}.png` 是本机产物，不入 Git。
  两张图片完成后才通过 `mutateTargetFacts` 发布制作记录，成功替换后清理旧版两个文件。
- `Saved/finished/<page-id>.json` 只保存本机进度和错误。服务进程失联后显示中断，用户重新输出；
  不自动恢复任务，不维护制作历史或旧格式兼容。
- 不额外备份候选底图。原候选存在时直接使用；只改文字时复用当前无字成品。两者都缺失时，
  需要 Agent 根据制作记录重新生成候选，再从页面输出，不提供自动重跑文生图入口。

`finished-http.mjs` 提供 `GET /api/projects/<id>/finished`、`GET .../finished/jobs`、
`POST .../finished/output`（`page_key`、`candidate_id`）、`POST .../finished/output-batch`
（可选 `chapter_id`）和 `POST .../finished/export`（`variant: lettered|clean|both`、可选 `chapter_id`、可选 `preview: true`）。
读取成品支持可选 `page_id`，同时返回当前候选数量、唯一候选 ID 与批量跳过原因。
批量输出对范围内尚未制作／内容过时／成品文件缺失的页面串行执行同一准备-输出路径：采用当前唯一候选，
零张或多张候选的插画页跳过并在响应中列明，文字页直接制作；输出中或已就绪的页面不重复排队。
排队后准备执行时再次检查唯一候选是否保持一致，变化时本页失败，不自动换图；
单页失败不中断后续页面，同一项目重复提交批量返回 409。提交时先为全部目标写入排队占位任务，
再逐页准备执行，全局任务列表与浏览器标题的剩余数量随完成逐页递减。`force: true` 时已就绪页面也排队，
用于样式代码变化后的整批重新嵌字（候选未变会复用超分底图）；样式与渲染代码不进入内容快照，
代码层面的视觉变化不会产生「内容过时」标记，需要重新嵌字时选择重新制作全部。
准备操作走 `mutateDerived`，耗时处理在锁外，发布时重读并校验本页成品目标和页面存在性。
制作期间继续编辑页面不会改写本次快照，新成品按当前唯一候选／文案／布局差异显示内容过时。

超分使用 ComfyUI 原生 LoadImage → UpscaleModelLoader → ImageUpscaleWithModel → SaveImage。
权重为资源目录登记的 `2x-AnimeSharpV4_RCAN.safetensors`，由 Agent 安装；本机端点检查本机文件 SHA。
支持工作台当前选中的远程 ComfyUI：通过 HTTP 上传底图、提交和取回图片，不访问远程机器的文件路径；
远程按节点提供的模型清单检查文件名，实际加载错误由 ComfyUI 返回，不声称验证了远程权重 SHA。
沿用 ComfyUI 本身的串行执行，不增加工作台队列类型，不支持成品任务排序、暂停或自动续跑。
成品运行记录投影到全局任务列表、任务详情与历史，显示等待、超分、嵌字、保存和终态；
只展示实际阶段与耗时，不估算超分百分比。每页保留最近一次输出任务，重新输出覆盖该页任务记录。

`finished-render.html` 通过 Playwright 复用 `WorkbenchLetteringOverlay`，按目标尺寸渲染透明文字层，
等待字体与爱心加载后用 Sharp 合成；文字页改用共享的 `TextPageArtwork` 静态组件，底图为 2 倍候选出图尺寸（当前渲染配置 recipe 分辨率）的纯黑图，
跳过超分与候选校验。单页输出每次启动独立无头浏览器；批量输出共享一个浏览器与页面（`createFinishedRenderer`），
页面与字体只加载一次，浏览器崩溃时重建重试一次，批量结束关闭。Windows 使用本机 Edge；其他设备需要安装 Playwright Chromium
（`npm --prefix <仓库根>/app exec -- playwright install chromium`）。预览和输出共用组件、样式和排版算法。
默认字体霞鹜文楷以 webfont 形式内置在 `app/public/fonts/lxgw-wenkai/`（OFL，unicode-range 子集，按需加载），
预览、成品渲染与移动端浏览器使用同一字体文件，不依赖设备系统字体；未覆盖字符仍回退系统字体，
不固定历史浏览器或回退字体版本，不保证这些字符跨环境逐像素还原。

## 查看与分享

只显示嵌字版文件大小与实际分辨率，卡片与大图预览嵌字版。新增页面显示尚未制作，删除页面从列表与导出排除，
不自动清理删除页的制作记录和图片；页面排序、跨章节移动无需重新制作。

成品卡片用 `001`、`002` 编号；点击图片复用候选原图查看面板。左右键在当前范围的已有成品间翻页，
跳过未输出页面；候选查看时左右键切换候选。切换图片会重置缩放。
大图直接加载原始 PNG，缩放通过图片实际显示尺寸完成，不放大缩略图或已缩小的合成图层。
默认适合窗口，百分比表示相对于原图的实际显示比例；「原始大小（1:1）」按原始像素尺寸查看。
剧情候选大图复用编辑器的实时文案与布局（含未保存修改），以原图比例绘制只读嵌字层；
嵌字层跟随底图尺寸、缩放与拖动，桌面和手机共用。成品图片已经嵌字，不重复叠加。
缩略图右键菜单「删除成品」通过 `DELETE /api/projects/<id>/finished`（`page_key`、`expected_sha256`）删除双版本图片、
制作记录与任务状态，保留页面和候选。删除使用 `mutateTargetFacts` 校验当前记录指纹，制作期间禁止删除。

导出直接打包所选范围已有的成品，按当前索引编号，缺页保留编号空缺。
内容过时但尚未重新输出的页面，仍导出上一次成品。ZIP 只有嵌字版／无字版文件夹内的 PNG，不包含清单；图片不附带 ComfyUI 工作流文本。
「导出」弹窗选择图片 ZIP 或轻量 HTML，以及嵌字版／无字版／两个版本。
轻量 HTML（`preview: true`）导出单个 `<项目>-预览.html`：复用 media-variants 的 1024px WebP 缓存，
base64 内嵌，只含图片与右下角半透明当前页码，不显示标题；「两个版本」按先嵌字后无字顺序拼接。
工作台「阅读预览」与离线 HTML 共用 `app/shared/finished-reader.mjs` 的文档、样式及交互：
支持垂直／水平连续阅读，水平模式将鼠标纵向滚轮映射为横向滚动，切换方向时保持当前页。
两种导出都先取文件清单再逐张流式写出，不在服务器内存攒整包；响应头 `x-export-total` 通告总字节数
（HTML 为精确值，ZIP 为图片原始大小之和，略低于实际），前端据此显示下载百分比并在完成后弹出提示。
应用只写入制作记录，不自动提交 Git。ZIP 经网页响应下载到访问者当前设备，远端工作台同样可用，
不依赖文件系统共享或服务端目录的本机路径。

验证：`npm --prefix <仓库根>/app test` 包含成品保存、替换失败、复用超分、增删排序和 ZIP 文件列表；
`npm --prefix <仓库根>/app run test:finished-ui` 验证共享嵌字渲染、导航与浏览器下载。
实际 AnimeSharpV4 验证单独在本机运行，不由自动测试调用 GPU。

成品卡片仅显示可点击编辑的编号、尺寸与嵌字文件大小；章节、sequence 和页面标题在编号悬停说明中展示。
页面编辑区提供「查看成品」和单页输出；缩略图右键（触屏长按）删除。共用大图面板两侧提供半透明翻页按钮。
成品标题区保留范围和刷新状态图标，下方固定小字统计「尚未制作／内容过时／成品文件缺失」，旁边图标打开说明。
工具栏固定提供「阅读预览」「导出」「批量制作」，不因待处理数量改变布局；刷新成功使用短暂提示。
「批量制作」弹窗列出目标页和跳过原因，可选仅制作待处理页面或重新制作全部（候选未变时复用超分底图）。
批量运行期间按钮禁用，排队页面进入全局任务列表并计入
浏览器标题的剩余数量，各页进度仍由卡片状态显示。

文字页预览和输出共用工作台 `render_capabilities.text_page` 的实际成品尺寸（生效 recipe 尺寸 ×2），不以项目名义宽高比代替。尺寸解析失败时仍可编辑文字，预览标明草稿并禁用输出。
