# 页面生成实验

`anima-base-depth-v1.json` 是两步生成的固定配方和依赖身份，适用于 Anima Base v1.0。
由服务端在普通候选工作流上展开草稿、深度提取和最终控制分支，不需要手工编辑工作流。
每个任务冻结完整配方、草稿文本、风格 LoRA、独立草稿 seed 和展开后的工作流。

配方固定草稿 16 步、两阶段 shift 5；尺寸、CFG、采样器和调度器沿用最终候选配方。
草稿仅加载项目风格 LoRA。最终分支保持当前结构化／自定义选择的完整 LoRA。
每张候选都有独立草稿 seed，不通过清理 ComfyUI 全局缓存强制重跑。

模型文件与自定义节点安装位置见 [运行环境](../../docs/reference/setup.md#两步生成实验)。
权重不进入 Git。普通生成不读取这个实验开关，不改变原有采样设置。
