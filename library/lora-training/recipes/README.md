# LoRA 训练方案

本目录保存可随仓库和项目任务引用的版本化训练语义。当前唯一路线是 Qwen-Image-2.1
（BF16），方案描述会改变训练目标的字段：模型家族、最大像素数、LoRA rank、学习率、
梯度累积、优化器与调度器、精度和冻结的 LoRA 注入模块清单。

总步数、保存间隔和 Seed 属于单次运行设置（settings.json 的 run_defaults），不写入
训练方案；梯度累积是语义训练参数，保存在方案 overrides。工作台在预检和 Run manifest
中记录本次实际值。

方案 ID 一经被任务引用便不原地改变语义；需要调整基线时新增版本化文件。
