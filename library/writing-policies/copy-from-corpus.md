# 后期文案优化与语料参考

原型阶段按用户提供的基础文案原样分配到页面。文案优化是后期独立任务，不随分页或出图自动开展。

用户要求优化时，先读当前单元、基础文案和必要角色背景，保持原意、说话人和上下文一致。语料库 library/writing-corpus/ 只供措辞、语气和节奏参考，不要求照抄、拼接原句或追求重合度；不把语料情节带入项目。

需要检索时使用 app/scripts/corpus-search.mjs（corpus:search）；阅读命中上下文后自行组织符合当前页面的表达。不设逐页条数配额，不强行补旁白或增加剧情。

不再建立文案出处映射。现有 text-sources 文件与接口尚待功能变更移除，本规范不授权删除它们，也不要求继续维护。文件名暂保留以维持现有文档引用，其内容已替代旧照抄方法。

文案通过 narrative read/save 写入，已有 dialogue ID 保留，新增项由服务分配。删除或重排条目前检查排版引用。文案修改通常不要求重生成图片；不擅自修改用户输入材料或文字样式。
