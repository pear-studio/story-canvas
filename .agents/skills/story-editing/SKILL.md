# 故事与页面编辑

先读[创作规则](../../../docs/creative/guide.md)，按任务表读取必要上下文。

1. 查询骨架、索引和本次目标，取得真实身份；机械操作直接查相应工具 help。
2. 给出当前改动草案，按创作规则完成确认；已确认范围内的普通操作不重复请示。
3. 用结构操作落实组织变化，用页面编辑操作保存正文；只有实际入镜人物参与画面引用。
4. 需要验证图或页面 Prompt 时使用 `prompt-authoring`；依赖验证结果的页面不提前铺开。
5. 核对当前范围的改动并交付入口，停在本次委托边界。

目录或资料归属不清时查[项目事实](../../../docs/reference/project-files.md)；没有工作台工具时用[集成说明](../../../docs/agent/README.md)的 CLI。
