# 视觉方向比较

按 docs/creative/guide.md 读取相关事实，与用户明确本次要比较的方向和范围。普通首轮原型不因审美尚可改进而自动升级为探索任务。

选择能看出差异的最小载体，给出少量清楚方案；不同时改变所有条件后声称知道哪项起作用。角色新子设定、LoRA 和故事改动遵守各自确认边界。

通过 prompt-authoring 与正常 read/save 落实本次方案，生成数量和轮次按当前约定；未特别指定时使用普通三张与一次严重问题修正规则。保留所有比较候选，不替用户筛选、删除或选择。

说明观察到的差异和不确定性，让用户决定方向。只实施用户明确要求的应用范围，不在方向确认后自动铺开所有页面。需要回答客观可靠性问题时提出 generation-testing 建议，不自动转入长期试验。
