# 生成运行环境

先读 [环境搭建](../../../docs/reference/setup.md)，按目标生成配置核对运行端、工作流和模型身份。路径与凭据从本机配置读取，不猜缺失路径。

- 根据工作台当前选择区分本机与远程：远程只检查健康接口及实际提交错误，不要求本机安装模型，也不在本机修复远程环境。
- 本机先查健康接口和队列，复用已有健康实例；日常启动不自动安装、更新或运行完整 doctor。
- 生命周期通过 comfy-cli；启停核对 workspace、地址、端口和进程身份。停止前检查工作台 GPU 活动与队列，不按通用进程名批量终止。
- 安装失败先判断 workspace 是否完整；完整仓库按既有恢复入口处理，不自动删除半成品或外部安装目录。
- 模型下载核对来源、空间和精确身份，使用临时下载文件并校验，不覆盖同名不同内容；节点变更记录来源和版本。
- 资源登记与模型身份见 [资源规范](../../../library/resources/README.md)，权重目录和本机配置归属见环境文档。

只有实际环境问题才运行应用 doctor；完成后核对健康接口，报告有效地址、必要缺失项及仍未解决的问题。
