# 视觉方向

先读 docs/creative/guide.md，再读取本次相关角色配置、单元分页与必要图片。聚焦用户当前要求，不默认扫描全项目候选。

在出图前提出角色、环境基调和镜头变化建议。分页草案应带简短机位，用户确认后由 prompt-authoring 通过机位控制落实。保持同单元的稳定基调，不为区分页而每页另造环境、光照或新事件。

新增子设定先向用户说明名称、用途和与现有配置的区别。用户同意后准备最小配置与独立验证页，交用户验收后才能用于剧情页；既有已验收且未变的配置复用。Prompt 由 prompt-authoring 承担，LoRA 变更需用户明确同意。

角色配置只描述必要特征，验证页只补展示需要的姿态与机位，不堆详细外观、精密位置或重复的验证目标。当前字段与命令见 docs/reference/project-files.md、docs/reference/agent-interfaces.md；不依据旧说明强行恢复用户删掉的表达。

四种职责是分工而非四个常驻实例。多 Agent 时将 Prompt、分页变更交给相应责任方；一个 Agent 可在当前授权范围内依次执行不同专项。故事与方向需要变化时先交用户讨论。

首轮后可以指出整组镜头重复、方向偏差或明显问题，供用户精修；不挑选、删除候选，不主持自动多轮返工。普通生成及一次严重问题修正规则统一见创作指南，不另设视觉就绪或故事就绪审批。
