# 参考图搜寻

1. 明确角色、造型、镜头或动作缺口，不硬设分类数量；用户指定来源时直接处理。
2. 回溯作者／官方页，关联作品、原图、作者和视频时间点；Wiki、标签和缩略图只作线索，转载不称作者原图。社区素材按授权收集，明确禁止 AI 使用的作品不加入训练候选。
3. 下载后实际解码、看图并核对身份；优先清晰完整原图，再按独立画面和镜头近重复去重，只保留最佳代表。其他 Agent 的采集也复核。
4. 不裁剪、缩放、修水印或重排版。视频优先取用户指定时间点；授权自行筛选时按镜头和信息变化取帧。测试版及未发布造型标明不确定性。
5. 交付只含图片的验收目录，来源关联留在临时采集区；汇报目录、独立文件数、覆盖和缺口。用户筛选后以最终目录为准，不从缓存补回。
6. 用户确认前不导入正式资产；委托导入、裁剪或训练后转入 `lora-training`。不生成联系表或额外说明文档。

Pixiv 核对作品页、多页原图和限制，不凭 ID 猜地址；图站沿 source 回作者；Bilibili 区分动态原图、封面、截图及社区 3D；官方媒体包避免只取预览。403、空列表或失效入口不等于无素材，少量验证后换来源。签名／UI 不自动淘汰，保留原图并说明关键内容损伤风险。
