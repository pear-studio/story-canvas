# 参考图搜寻

来源回溯、访问受阻与视频取帧见 [素材搜寻](../../../docs/reference/lora-material-sourcing.md)。先明确角色、服装、镜头或动作的缺口，不硬设各类数量；用户指定来源时直接处理该来源。

- 优先原始、清晰、完整文件；页面标题和缩略图只作线索，下载后逐张核验身份、造型和实际信息价值。
- 官方、社区和测试版来源可区分；社区素材按用户授权范围收集，留意作者明确限制。
- 先精确去重，再按画面、cutout 和镜头识别近重复；同一画面比较后只保留最佳代表，不按分辨率累计版本。
- 搜寻阶段不裁剪、缩放、修水印或重排版。视频优先由用户指定时间点；获授权自行筛选时按镜头与信息变化取帧。
- 交付只含图片的验收目录；来源页、原图地址、作者和视频时间点关联放在临时采集区，不混入验收目录。
- 汇报目录、独立文件数、覆盖和缺口即可；用户删选后以最终目录为准，不从缓存补回已删除图片。

用户确认前不导入正式资产；明确委托导入、裁剪或训练后转入 `lora-training`。不生成联系表、额外说明文档或自动扩展收集任务。
