# 角色参考图搜寻

只负责搜寻和整理角色参考图片，输出供用户人工验收的图片目录。不要生成联系表、清单或其他非图片文件；不要在用户确认前把图片写入正式项目资产。

社区检索、原图回溯和访问受阻时，按需读 [素材搜寻参考](../../../docs/reference/lora-material-sourcing.md)。用户已指定社区来源时优先处理该来源，不必重新走一遍官方搜寻；不要把“少量补充”的官方活动图取舍套用到用户明确要求的同人图收集。

## 工作流程

1. 先把目标拆成自然语言的覆盖项：角色身份、服装或造型差分、脸部与发型、全身与局部、正侧背面、静态与动作、室内外场景。把已有图片和缺口列出来，不为每项硬设数量。
2. 按来源可靠性搜寻：
   - 角色官网、游戏公告、官方视频和官方社交账号；
   - 官方活动、联动页面和官方商品详情；
   - Wiki、Fandom 或媒体转载只用于索引和补充游戏画面，并尽量回溯到原始来源；
   - 社区图片只有在用户提供或明确授权后才加入，不能与官方素材静默混合。
   - 搜寻时就优先寻找可取得的原始、高分辨率、完整画幅文件；不要先把低清缩略图当成候选，等验收后再补清晰版本。同一画面有多个来源时，先下载并比较清晰度、压缩、遮挡和来源可靠性，再决定保留哪一个。
   - 页面标题、缩略图、文件名和搜索摘要都不是造型证据。下载后逐张目视核对角色、服装、镜头和来源页面；不匹配的活动图、错误幻灯片或被误标的图片直接排除。
3. 以“独立画面信息”为单位收集。相同角色 cutout 在不同海报、分辨率、横竖版或商品页面中的复用只保留一个最终代表；同一画面有多个文件时，优先保留原始、清晰、完整、无遮挡且来源更可靠的版本；同一视频连续帧只保留能体现不同镜头、姿势、服装细节或表情的代表帧。
4. 保留原始画幅和原始文件，不裁剪、不缩放、不修水印、不重排版。需要视频素材时可以提供视频链接，也可以先下载到临时目录；视频本身不放入图片验收目录。
   - 当镜头是否值得保留需要用户判断时，先请求用户挑选画面。用户只需回复秒数或时间点，例如 `42`、`87.5`，Agent 按指定时间提取完整画幅的帧并放入验收目录；把裁剪留给用户或工作台。
   - 只有用户授权 Agent 自行筛选时，才按镜头切换和信息变化抽取少量代表帧，不按固定时间间隔大量导出。
5. 输出只包含图片的验收目录；官方、同人和测试版来源需可区分，分别交付时给出明确的最终目录。默认使用扁平目录，文件名采用小写自然分类加三位序号，例如 `maid-001`、`on-campus-001`、`screenshot-001`；不要依赖原文件名，也不要把 JSON、文本、视频或联系表放入该目录。临时采集区另存最终文件名与作者、来源页、原图地址的对应关系，但不要复制到验收目录。
6. 做两层去重：先查文件级精确重复，再按构图、角色 cutout、镜头和排版识别近重复。同一画面的多个版本只保留前一步比较后选出的最佳版本，不因分辨率更高就额外保留重复图。
7. 用以下标准决定是否放入验收目录：
   - 角色身份或服装结构清楚；
   - 能提供已有图片没有的姿势、镜头、表情、服装细节或场景信息；
   - 文字、UI、水印、多人或商品摄影可以存在，但不能遮掉主要信息；
   - 3D 游戏内画面优先作为身份和姿态基线；官方二维 MV、动画或宣传静帧可少量补充脸部、服装和动作，但要标明它们与游戏画面的视觉域不同；联动图、商品图和手办摄影主要用于核对服装层级、配件或背面，通常只保留少量参考，不与游戏画面等量扩充；
   - 不因分辨率、画幅或来源类别设置僵硬门槛，按实际信息价值取舍。
8. 搜寻结束后只汇报：最终验收目录中的图片数量、各自然分类数量、来源覆盖、明确排除项和仍然缺失的覆盖项。同一画面的不同来源只按最终选中的一张计数，不单独列出版本类别。对视频帧至少保留来源视频和时间点在临时采集记录中。让用户直接检查图片目录；用户未确认前不要继续扩展为其他处理流程。
   - 多角色统计同时说明独立文件总数和各角色出现数；合图可计入多个角色，但不能把角色出现数相加当作文件总数。
   - 用户删选后再整理时，重新枚举已交付的最终目录；不要从采集缓存或子 Agent 中间目录补回已删除图片。用户授权裁剪或导入数据集后转入 `lora-training`，不再受本技能搜寻阶段的“不裁剪”约束。

## 取舍重点

- 优先补“服装差分 × 镜头/动作”的空缺，而不是继续堆同一张宣传立绘的变体。
- 搜寻的目标是直接找到可用的最佳版本：优先查官方原图、原始静态宣传图和高质量视频源，再用转载页做索引或补充；低清版本只有在没有更好来源，或它本身提供独立画面信息时才保留。
- 清晰的单人全身、脸部近景和有独立动作信息的完整游戏画面优先。
- 看人物实际占用的像素、脸部清晰度与特效遮挡，不只看整张图或视频的标称分辨率。超分不能作为保留严重模糊、人物过小或结构错误图片的理由；有独立参考价值的小图可以保留并注明。
- 同人换装、摘眼镜等差分按用户的角色或服装目标判断，不因不是默认造型而一律排除；单独标明差分，不承诺增加图片就能提高训练稳定性。
- 对官方活动、联动和商品图保持小比例；它们适合验证服装层级、配件、背面和造型边界，不能自动视为游戏内画面。
- 对视频优先让用户按秒数指定画面；用户授权自行筛选时，再按镜头切换和信息变化选帧，不按固定时间间隔大量导出。
- 同一画面有多个版本时，分辨率只是比较因素之一；清晰度、完整画幅、遮挡、黑边、水印、排版、压缩和来源可靠性都要一起目视比较，选择综合质量最佳的一张。
- 发现来源页、缩略图或搜索结果与实际画面不一致时，以实际画面为准并记录为排除经验，避免把错误来源继续传播到后续整理。
