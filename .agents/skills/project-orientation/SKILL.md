# 了解现状与确定当前一步

先读 docs/creative/guide.md。按问题读取 project、创作约定、材料索引、outline、角色与页面索引，再补当前范围的事实；不默认扫描全部图片、历史或运行环境。

说明已有内容、当前判断和真正待决的问题。尚未分页的后续 sequence 是合法骨架，不误报缺页。用户只要求了解或讨论时不写事实、不生成。

先给具体建议，只问影响目标、故事、审美或范围的问题。用户确认当前一步后使用对应专项技能，不默认组建团队或启动完整生产。用户已有明确授权时直接沿用，不重复确认。

交付简短现状与下一步建议；继续执行仅限用户已明确的范围。跨会话确需交接时记录目标、已确认决定和未决事项，不建立项目阶段状态。
